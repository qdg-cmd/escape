# 🏫 버려진 학교 (탈출) — 3D 학교 방탈출 웹 앱

> **어두운 밤의 학교 과학실에서 깨어나 옥상까지 다섯 곳을 차례로 빠져나가는 1인칭 3D 학교 방탈출 웹 게임**

🌐 **실시간 플레이 링크**: [https://qdg-cmd.github.io/escape/](https://qdg-cmd.github.io/escape/)

---

## 🌟 주요 특징

1. **학교 테마 5개 스테이지 완전 구현**
   - 1스테이지: **과학실** (도어락 PIN 번호 퀴즈)
   - 2스테이지: **교실 복도** (각 반 체크 차트 조합 암호)
   - 3스테이지: **도서실 / 준비실** (도서 분류 시각순 다이얼)
   - 4스테이지: **교무실 / 사물함** (출석부 명단 순서 사물함 해제)
   - 5스테이지: **학교 옥상** (밸브 조작 및 개교기념일 자물쇠 최종 탈출)

2. **다기종 반응형 & 갤럭시 폴드 4 최적화**
   - PC: 마우스 룩(Pointer Lock) + WASD 이동
   - 모바일: 가상 듀얼 조이스틱 (왼쪽: 이동, 오른쪽: 시선 회전)
   - 초소형 화면(5.5인치) 및 갤럭시 폴드 4 커버 화면(340px) 최적화 레이아웃
   - PWA(프로그레시브 웹 앱) 지원 — 홈 화면에 추가하여 전체화면 앱으로 플레이 가능

3. **교사/관리자 퀴즈 커스텀 & 전 기기 동기화**
   - 인트로 화면의 **[문제 설정]** 버튼에서 각 방의 퀴즈 문제와 정답을 원하는 대로 변경 가능
   - **[공유 링크 복사]** 버튼으로 문제를 포함한 URL을 생성하여 학생들에게 링크 하나로 전달
